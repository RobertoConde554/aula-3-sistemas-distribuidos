# Comunicação Cliente-Servidor UDP

Nesta aula foi desenvolvido um sistema simples de comunicação entre **cliente e servidor utilizando Python e sockets UDP**.

* Foi utilizado o módulo `socket`.
* O servidor foi configurado para utilizar a porta **5000**.
* O cliente envia uma mensagem para o servidor.
* O servidor recebe e exibe a mensagem.
* Em seguida, o servidor envia uma resposta ao cliente.
* A comunicação foi realizada através de `localhost`.

A atividade demonstrou na prática como funciona uma **comunicação básica entre cliente e servidor utilizando o protocolo UDP**.
